Full-Stack Integration & Testing Guide
Backend Connection & Swagger Verification

Before testing, ensure your Spring Boot CrudService application is running on port 8081. You can open Swagger UI directly at: http://localhost:8081/swagger-ui/index.html

End-to-End User Flow Testing
  1. Add Record: Go to Add Equipment. Notice that no ID field exists. Click "Fill Valid Sample" and submit. You will see a success toast showing the auto-generated database ID.
  2. View/Display: Automatically redirects to Equipment List where your new item is displayed with formatted currency and operational badge.
  3. Delete Record: Click the red trash icon on any row. Confirm the action in the delete modal. The item is deleted via DELETE /gym/Delete/{id} and removed from the list.
  4. Edit Record: Click the blue pencil icon on any item to update details via PUT /gym/Update/{id}.
Input Validation Testing
  • Blank Required Inputs: Click "Test Blank Input" and submit → clear red inline validation error messages appear for all required fields.
  • Invalid Ranges: Click "Invalid Cost Test" (negative cost: -$50.00) → triggers "Purchase cost must be greater than zero".
Note: All changes are saved directly in your PostgreSQL database (exam_2400030107).
